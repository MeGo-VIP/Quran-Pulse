# نور الإيمان - القرآن الكريم

موقع/تطبيق ويب (PWA) للاستماع إلى القرآن الكريم — سورة كاملة أو آية بآية — بصوت مجموعة واسعة من القراء، مع مواقيت الصلاة والتقويم الهجري.

## محتويات المجلد

```
index.html              الصفحة الرئيسية (كل التطبيق تقريبًا في ملف واحد)
manifest.json           بيانات التطبيق لإمكانية التثبيت (PWA)
sw.js                    Service Worker لتشغيل واجهة التطبيق بدون إنترنت
icons/
  icon-192.png
  icon-512.png
  icon-maskable-512.png
```

## الرفع على GitHub Pages (أسهل طريقة مجانية)

1. أنشئ Repository جديد على GitHub (مثلاً باسم `noor-al-iman`).
2. ارفع الملفات أعلاه بنفس المسارات (حافظ على مجلد `icons/`).
3. من إعدادات الـ Repository: **Settings → Pages → Source** اختر الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة أو اثنتين سيكون الموقع متاحًا على:
   `https://<اسم-المستخدم>.github.io/noor-al-iman/`

> **مهم:** يجب أن يبقى اسم الملف الرئيسي `index.html` (كما هو) حتى يفتح GitHub Pages الموقع تلقائيًا دون الحاجة لكتابة اسم الملف في الرابط.

## التثبيت كتطبيق

بعد الرفع على رابط HTTPS فعلي (مثل GitHub Pages)، سيظهر زر "📲" في أعلى الصفحة لتثبيت الموقع كتطبيق على الهاتف (Android/Chrome مباشرة، وعبر "إضافة إلى الشاشة الرئيسية" في Safari على آيفون).

ملاحظة: ميزة التثبيت والعمل دون إنترنت تحتاج أن يكون الموقع على HTTPS — لن تعمل من فتح الملف مباشرة من الجهاز (`file://`).

## مصادر البيانات (مجانية، بدون مفتاح API)

- **mp3quran.net** — قوائم القراء وتلاوات السور الكاملة.
- **api.alquran.cloud** — تلاوات الآيات منفصلة (وضع "آية بآية").
- **api.aladhan.com** — مواقيت الصلاة (حسب الموقع الجغرافي أو مدينة يدوية).

## أفكار للمرحلة القادمة

- بوصلة القبلة.
- تتبع ختمة القرآن وآخر نقطة قراءة.
- أذكار وأدعية مصنفة وقابلة للبحث.
- دعم لغات متعددة للواجهة نفسها.
